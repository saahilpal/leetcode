# Reverse Linked List

**Difficulty:** Easy  
**Pattern:** Linked List  
**Language:** cpp  
**LeetCode:** https://leetcode.com/problems/reverse-linked-list/submissions/1938921565/?envType=problem-list-v2&envId=linked-list

---

## Intuition
To reverse a linked list, we need to change the direction of the next pointers. Normally each node points to the next node, but while reversing we make it point to the previous node.

To do this safely, we use three pointers: prev, curr, and next.

curr moves through the list, prev stores the reversed part, and next temporarily saves the next node so we don’t lose the remaining list.

---

## Approach
Initialize three pointers:
prev = NULL, curr = head.

Traverse the linked list while curr is not NULL.

Store the next node using next = curr->next.

Reverse the link by setting curr->next = prev.

Move prev forward to curr.

Move curr forward to next.

Repeat until the list ends.

Finally prev will point to the new head of the reversed list.

---

## Example Walkthrough
1 → 2 → 3 → 4 → NULL

Step 1

prev = NULL
curr = 1

Step 2

1 → NULL
prev = 1
curr = 2

Step 3

2 → 1 → NULL
prev = 2
curr = 3

Step 4

3 → 2 → 1 → NULL
prev = 3
curr = 4

Step 5

4 → 3 → 2 → 1 → NULL
prev = 4
curr = NULL

Return prev as the new head.

## Code

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* curr=head;
        ListNode* prev=NULL;
        ListNode* Next;
        while(curr)
        {
            Next=curr->next;
            curr->next=prev;
            prev=curr;
            curr=Next;
        }
        
        return prev;
    }
};
```
